# Bike Link 서울 분석 실제 검증

검증일: 2026-11-16. 공개 화면·공개 도구 출력·서울시 공식 원본을 비교했다. 사이트 코드는 수정하지 않았다. Solar 질문은 1회 실행했다. 서버 로그나 API 전송 자체를 감청하지 않았으므로 모델명·토큰은 사이트가 보고한 값이다.

## 원본과 방법

- OD: https://data.seoul.go.kr/dataList/OA-21229/F/1/datasetView.do 에서 tpss_bcycl_od_statnhm_202610.zip 다운로드. 31개 일별 CSV를 CP949로 읽어 전체 재집계. 파일 SHA256은 raw_recalculation.json에 보관.
- 마스터: https://data.seoul.go.kr/dataList/OA-21235/S/1/datasetView.do 에서 CSV 전체 다운로드. 2026-11-16 조회 당시 3,437개 항목. 사이트는 2026-11-09 수집본이므로 동일 시점 스냅샷은 아니다.
- 집계 기준 출발시간과 도착시간을 분리. 두 집계를 합쳐 이용횟수를 계산하지 않음.
- PageRank: 출발시간 자료로 가중 방향 그래프 구성. ST- 형식이 아닌 X 노드 및 연결 제외. self-loop 포함, 감쇠계수 0.85, 균일 초기값·teleportation, L1 오차 < 노드 수 × tol. tol=1e-6과 1e-12 비교.

전체 OD 쌍은 435,906개지만 X 도착 노드를 포함한다. 유효 ST끼리의 OD는 433,400개다. 제외된 2,506개 쌍의 이용량은 18,535건이고, 유효 그래프의 가중치 합은 4,227,419건이다. 총이용량·전체 OD·유효 그래프는 서로 다른 모집단이다. 예를 들어 ST-3388 전체 대여는 15,552건, 그래프 유효 출차는 15,476건이다. 화면 '전체 OD 연결 ... 지역 내 실제 연결 관계'에 무효 ID 포함 여부를 명시해야 한다.

## Solar 실제 실행 결과

질문: 서울 2026-10-01~31 대여소 수·이용건수와 ST-2264 대여/반납/순유출, 사용 도구·기간·제외 기준을 제시하고 원본에 없는 값을 추정하지 않도록 요청.

- 화면은 모델 solar-mini4-260922, 사용 토큰 18,544를 보고했다.
- Solar 선택 도구: get_region_overview, get_station_details.
- 서버 근거 보강 도구: get_station_imbalance, get_station_role_history.
- 화면 요약과 공개 JSON을 독립 합산한 결과 총량·시간대·일별·요일별 합이 모두 4,245,954건으로 일치했다.
- Solar 원문 주요 수치는 원본 재계산과 일치했고, −1,582건을 순유입이라고 해석한 부분도 정확했다.
- 그러나 사이트 자체 검증기는 원문을 보류하고 '실제 도구 기반 요약'을 대신 표시했다. 검증 실패를 성공으로 기록할 수 없다.
- 원문에는 '제외 기준은 별도로 적용하지 않았으며'라는 문장과 '마스터 유효 좌표와 공식 검증 정보를 확인한 항목 기준'이라는 문장이 함께 있어 모집단 설명이 불명확하다. 2,759개는 출발 대여소 수이며 공식 마스터 전체 규모가 아니다.
- 보류 사유는 수치·ID·일별 극값·종료 상태 검증 중 하나라는 포괄 문구다. 특정한 수치 오류가 원인이라고 단정할 수 없으므로 실패한 주장·도구 경로·예상값·실제값을 기록하는 로그가 필요하다.

## 불균형 후보 전체 수 재계산

유효 ST 노드 2,762개에 대해 총이용량 하위25%를 제외한 뒤 절대 불균형 비율 상위10%와 방향 지속성 상위25%를 동시에 적용했다. 임계값은 총량 1,163.25건, 절대 비율 0.09600433917917194, 지속성 0.7096774193548387로 공개 도구의 반올림 표시와 일치한다. 이 정밀 임계값을 사용한 재계산 결과는 207개이며 대시보드 208개와 1개 차이가 난다. 후보 집합 전부의 일치는 확인하지 못했다. 경계값 반올림, 분위수 계산법, 서버 구현·자료 버전을 확인해야 하며 현재 근거로 어느 원인이 확정됐다고 말할 수 없다. 상세는 imbalance_recalculation.json에 저장했다.

## 수정·추가 확인 사항

1. ST-2264 '순유출 −1,582건'은 수식 변수로는 가능하나 운영 문구는 '순유입 1,582건'으로 명확히 표기.
2. '분석 대여소 2,759개'는 '기간 내 대여 발생 대여소 2,759개'로 명확히 표기. 유효 네트워크 2,762개와 구분.
3. 전체 집계에는 X 도착 기록을 포함하지만 그래프에서는 제외함을 표시하고 제외 쌍·건수를 기록.
4. PageRank alpha, tol, 최대 반복, self-loop, 방향, 가중치와 순위 동률 처리 공개.
5. K-means Silhouette 0.1236은 화면과 해석 보류 동작만 확인. 입력 행렬·전처리·표준화·seed·초기화 횟수·최종 라벨·평가 표본이 공개되지 않아 독립 재현 미완료.
6. 기간 안정성 버튼은 7일↔14일 ARI 0.6794(공통 2,749개), 14일↔30일 ARI 0.7164(공통 2,756개)를 표시했으나 이 값도 독립 재계산한 결과는 아님.
7. 이번 마스터 일치는 현재 공개 스냅샷과의 일치다. 사이트가 사용한 11월9일 원본 스냅샷은 별도 보관·대조 필요.

결론: 서울 주요 집계·표본 불균형·상위 PageRank는 원본 재계산으로 확인했다. 전체 결과를 검증 완료로 표현할 수는 없으며 불균형 후보 1개 차이, K-means 수치 재현과 Solar 검증 통과는 남아 있다.
