# 로컬 첨부 보관 안내

기존 첨부 14개는 로컬 파일을 보존하고 Git 추적에서 제외했습니다. 파일명·크기·SHA-256은 [첨부 목록](../docs/LOCAL_ATTACHMENTS.json)에 있습니다. 과거 커밋의 파일을 내려받아 원래 경로에 복원할 수 있으나, 신규 커밋에는 첨부하지 않습니다. 원 출처는 [데이터 출처](../docs/FINAL_DATA_SOURCES.md)를 확인하십시오.

5·6·7·8번 보고서는 서울 2026년 10월 사례이며 현재 서비스의 3도시 2025년 12월 비교와 다릅니다. [발표용 기간 안내](../docs/REPORT_PERIODS.md)를 먼저 읽으십시오.
