# 최종 발표·교수님 시연 가이드

## 권장 흐름

1. 대시보드에서 서울과 2026-10-01~31을 선택한다. 실제 4,245,954건과 핵심 발견을 확인한다.
2. ST-1481 발견 카드를 눌러 대여소 분석으로 이동한다. 이용량 1,640위와 PageRank 280위가 답하는 질문이 다름을 설명한다.
3. 시간대 패턴과 유사 대여소 TOP5를 보고, 7·14·30일 기간 비교와 군집 안정성 검증을 실행한다. 낮은 Silhouette는 숨기지 않고 역할 해석 보류로 설명한다.
4. 이동 패턴에서 실제 OD와 불균형을 확인한다. 네트워크 노드를 눌러 대여소 상세로 돌아갈 수 있다.
5. 전체를 선택해 단일 통합 화면의 5,169,532건·4,142개를 확인한다. 도시 간 가상 이동을 만들지 않았음을 설명한다.
6. 도시 간 비교는 총량 배율보다 공통 기간의 시간대·요일 비율을 사용하고 세종 연간 통계를 별도로 확인한다.
7. AI 분석 리포트에 질문을 입력한다. 실행된 도구, 고정된 도시·기간, 실제 근거 카드, 운영 검토와 한계를 차례로 보여준다. 실제 API 사용 토큰이 발생한다.

## 발표 핵심 성과

- 실제 서울 월간 집계 OD와 대전 11개월 760만 유효 Trip을 정규화하고 검산했다.
- 단순 이용량 순위에서 놓칠 수 있는 ST-1481의 연결 중요도를 실제 수치로 제시했다.
- ST-3031의 특정 시각 집중과 ST-2264의 기간 반복 순유입을 서로 다른 역할 후보로 구분했다.
- 세종 상세 데이터 부족, 낮은 군집 품질, 근사 중심성의 한계를 공개한다.
- AI는 자유 서술을 그대로 신뢰하지 않는다. 실제 비교 질문에서 잘못된 시간 해석을 발견했고, 원문 보류와 도구 기반 요약으로 서비스가 잘못된 기본 답변을 표시하지 않도록 했다.

## 발표에서 피할 표현

환승 거점 확정, 관광 대여소 확정, 재고 부족 확정, 재배치 효과 수치 예측, 전체 도시를 새로 학습한 K-means, 캐시 준비 시간을 포함하지 않은 속도를 모든 첫 요청의 속도로 설명하는 표현은 피한다.
