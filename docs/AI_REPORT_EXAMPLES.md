# AI 보고서 실제 출력 예시

## 서울 PageRank
질문: “서울에서 PageRank가 높은 대여소 TOP 5를 알려줘.”

실제 중심성 도구 결과의 상위 대여소는 ST-3388 (0.0035523), ST-3403 (0.0024785), ST-891 (0.0023559), ST-3390 (0.0022358), ST-1720 (0.0020777)이다. 이 값은 2026-10-25 및 2026-10-29 집계 OD의 전체 그래프에서 계산한 PageRank이다. 이용량 자체나 환승을 증명하지 않는다. 구조화 보고서의 순위 차트는 도구 결과에서 생성한다.

## 세종 군집 분석
질문: “세종에서 군집 분석이 가능한지 알려줘.”

실제 도구는 연도별 총 이용량만 확보됐다고 반환했고 `get_station_clusters.available=false`였다. 2025년 연간 총량은 2,629,483건이다. 대여소·시간대별 자료가 없어 군집 유형을 생성하지 않았다.

## 부산 중심성
질문: “부산의 대여소 연결 중심성을 분석해줘.”

운영 메타데이터만 확인된다. OD가 없어 `get_centrality_ranking.available=false`, 순위는 빈 배열이다. 중심성 값, 대여소 순위, 지도 좌표를 생성하지 않았다.

## 대전 이용량과 중심성
질문: “대전에서 이용량과 연결 중심성이 다른 대여소를 찾아줘.”

최종 추가 실호출에서는 중심성 상위 ST0412·ST1067·ST0191의 상세 이용량을 조회했다. ST0412는 대여량 232건(이용량 순위 12), 중심성 순위 1로 차이 +11이다. ST1067은 245건(순위 8), 중심성 순위 2로 차이 +6이다. ST0191은 330건(순위 2), 중심성 순위 3으로 차이 -1이다. 웹의 비교 표에는 같은 대여소 ID의 실제 대여량과 중심성 값이 나란히 표시된다. 두 지표는 단위와 뜻이 다르며, 불연속 2일만 관측했다.

AI 자유 서술은 해석이다. 근거 카드, 차트, 비교 표는 서버 도구 결과를 사용한다. 원문 응답의 모든 표현에 대한 자동 사실 검증은 아직 없다.
