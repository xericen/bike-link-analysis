분석 기준은 서울 2026-10-01~2026-10-31 집계 OD와 공식 대여소 마스터다. 순유출은 모든 결과에서 `대여-반납`이며, 실제 재고량이 없어 부족이나 재배치 필요를 뜻하지 않는다.

세 곳 모두 PageRank 백분위가 이용량 백분위보다 높고 최소 관측량을 충족했다. 그러나 이용량 중앙값 이하, 양의 순위 차이 상위 10%, PageRank 중앙값 이상을 동시에 요구한 규칙은 어느 기간에서도 충족하지 않았다. 따라서 “숨은 연결 거점”으로 확정하지 않는다. API는 위치, TOP 10 입·출 연결, 이용량/PageRank 백분위, 기간 민감도와 한계를 함께 반환한다.

같은 규칙에서 실제 검토 후보로 남은 사례는 ST-1481(이용 1,640위/PageRank 280위), ST-452(1,722위/625위), ST-451(1,515위/445위) 등이며 전체 후보는 54개다. 이 역시 운영 검토 목록이지 환승 역할의 확정 결과가 아니다.

## 불균형과 운영 검토 규칙

- ST-118: 대여 4,636, 반납 3,344, 순유출 +1,292, 비율 16.19%, 31일 모두 순유출. 평일 +1,108(18.18%), 주말 +184(9.77%).
- ST-2264: 대여 4,351, 반납 5,933, 순유출 -1,582, 비율 -15.38%, 31일 모두 순유입. 평일 -1,208(-15.71%), 주말 -374(-14.41%).
- 최소 총량 1,163.25 이상, 절대 불균형 비율 9.60% 이상, 반복성 70.97% 이상을 동시에 만족한 208개가 검토 후보였다.

하나의 임의 종합 점수는 사용하지 않는다. 저이용·고연결, 지속 순유출, 지속 순유입, 시간대 집중, 기간 역할 변화로 목적별 분류하며 각 임계값·관측 기간·한계를 반환한다. 매개 중심성은 최대 32개 노드 표본 근사다.

## Solar 검증

실제 브라우저에서 ST-875 검증 질문을 1회 호출했다. Solar는 도구 5건을 사용해 후보 제외, 실제 대여·반납, PageRank·순위, 기간 민감도와 한계를 답했고 총 15,377 토큰을 사용했다. 응답 수치는 도구 결과와 자동 대조한다. 최초 대조에서 주소·데이터셋 식별자의 숫자 조각을 분석 수치로 오인한 항목이 있어, 이후 식별자 문자열도 근거 집합에 포함하도록 검증기를 보정했다.

## 한계

서울 검증 기간은 한 달뿐이므로 계절 안정성을 판단할 수 없다. 서울은 개별 Trip이 아닌 집계 OD이며, PageRank는 환승·관광 기능의 직접 증거가 아니다. 대전과 서울은 자료 구조·기간·운영 방식이 달라 중심성 절대값을 직접 비교하지 않는다. 세종은 대여소별 이용·OD가 없어 연간 총량 외 분석을 제공하지 않는다.
