## 화면에서 볼 수 있는 내용

분석 결론 상단의 바로가기 버튼으로 이동한다. 도시 선택에 따라 해당 도시의 검증을 표시하며, 별도 연구 자료는 관측기간·참조 기준을 분리한다.

| 바로가기 | 표시 내용 |
|---|---|
| 데이터 처리 검증 | 도시별 실제 기간·원본 파일 수·정제 전/유효/제외·중복 기록, 일별OD·시간대대여반납·역 인근 이동의3개 대조 결과 |
| AI 오류·사용량 | 실제 잘못된 원문 사례와 보류 처리, 이전/축약 후 토큰 막대·합계,111개 통제 문장의 검사 유형별 건수 |
| 연결·시간 패턴 | 기본 기준과 PageRank10% 보조 실험의 평가기간 주변 관측 수요·상위3후보 일치, 비슷한 수요/다른 피크 시각 사례와 군집 분리도 |
| 서울 환승 비교 | 종로3가5→1호선을 거쳐 서울역까지6개 여정, 연결 열차번호, 대여반납·환승보행 가정18개 조합 |
| 개설 전후 관측 | 서울2025 설치 기록67곳→위치·이름 연결61곳→검토 조건 통과55곳, 대표3곳과 전체55곳·제외 이유 |
| 남은 확인 사항 | 프로젝트 전체의 완료 범위·미완료 이유·다음에 필요한 증거·공식 자료 링크 |

서울 환승·개설 관측은 **전체 또는 서울 선택**에서 표시한다. 다른 도시에서 서울 수치를 해당 도시 결과처럼 표시하지 않는다. 기존 대전9여정·서울 반납소5곳 거치대·기존 후보3곳 상세도 유지했다.

표를 펼치면 페이지 전체로 스크롤한다. 새로운 독립 메뉴나 고정된 하위 스크롤 영역을 추가하지 않았다.

## 이번에 더 수행한 분석

### 1. 서울 공식 시간표를 확보해 두 노선 환승 모델 구현

[서울 공식 열차운행시각표](https://data.seoul.go.kr/dataList/OA-22522/L/1/datasetView.do)의2025-09-30 공개 CSV를 실제 다운로드했다.

- 제공기관: 서울교통공사
- 원본:44,740,932바이트·532,832행·UTF-8 BOM
- SHA-256:`46b6d9e2c2e1e23632fa72208a3ca5dc6aeba9013c403ee6f52747fec2b9a9e2`
- [공식 명세](https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-22522&srvType=A&infSeq=4)에서STT=열차도착시간,EDT=열차출발시간,DAY=주중,급행여부0=일반임을 확인했다.
- 요일 누락109,481행은 평일이라고 추정하지 않았다. 각 구간에는 출발역의 출발시각과 도착역의 도착시각이 유효한 기록만 사용했다.
- 같은 호선·열차번호·방향·요일로 출발역과 도착역을 연결했다. 두 노선 환승은 실제 시간표상 다음 열차가 도착 이후 환승보행 가정을 만족할 때만 가능하다.

기존 서울1·2순위 후보의 답십리/장한평 접근 경로를 재사용해, **5호선→종로3가 환승→1호선 서울역**을 비교했다. 같은 원점·08:00/08:15/18:00 출발·같은 서울역 출구를 사용한다.

| 후보 | 08:00 도착시간 차이 | 08:15 | 18:00 |
|---|---:|---:|---:|
| 기존1순위 | 자전거 연계7.5분 빠름 | 7.5분 빠름 | 9.0분 빠름 |
| 기존2순위 | 자전거 연계15.0분 빠름 | 23.5분 빠름 | 16.0분 빠름 |

이 값은 **공개 시간표·현재 OSM·가정의 조합 모델**이다. 실제 환승·실제 통행시간·2025년12월의 정확한 시행을 검증한 결과가 아니다. 환승보행5분,역 진입/출구 각2분,대여반납2분은 가정이며,08시 출발에 대해 대여반납0/2/5분과 환승보행3/5/8분도 비교했다. 전체 교통망의 최단경로가 아니라 선택한 대표 환승 경로다.

실제 시간표의 열차번호·역코드·방향·출발/도착시각이 일치하는지, 전체 시간의 합이 보존되는지, 환승 대기가 음수가 아닌지 테스트했다. 영업일25시처럼24시를 넘는 시각도 처리한다.

원본은 로컬raw에 보존하며 Git 무시 정책을 확인했다. 대용량 CSV를 공개 저장소에 올리지 않았다.

### 2. 기존 개설 사례의 관측 변화55곳 추가

추가 자료를 만들기 전에 보유한 공식2026년6월 대여소 마스터와 서울2025년 전체 이용이력을 확인했다. 마스터에2025 설치 기록67곳이 있었다. 이름 일치·좌표5m·유일성으로61곳을 연결했다.

첫 이용일과 설치 기록 차이±14일,전후28일 확보,30m 내 사전 이용이 있는 다른ID 배제,비교지역 확보 조건을 적용했다. 비교지역은 같은 구·2.5km 밖·사전 주변 수요0.5~2배인 연중 이용 대여소 중 사전 수요 차이가 가장 작은 곳으로 선택했다. 사후 증가가 큰 곳을 골라 비교하지 않았다.

- 연결 실패6곳: 이름·위치의 유일 연결 조건을 충족하지 못함.
- 연결 후 제외6곳: 설치/첫 이용 차이14일 초과3곳,비교지역 조건을 만족하는 곳이 없는3곳.
- 조건 통과55곳: 개설 기록일순으로 대표3곳을 먼저 제시하고 전체55곳도 펼쳐 볼 수 있도록 했다.

| 대표 사례 | 첫 이용 | 주변 하루 대여 전→후 | 비교지역 전→후 | 두 변화의 차이 |
|---|---|---:|---:|---:|
| ST-3356 서울동물복지지원센터 동대문 | 2025-03-28 | 977.5→1,094.5 | 958.1→1,126.5 | -51.3건/일 |
| ST-3357 공릉동효성아파트 앞 | 2025-04-09 | 918.3→1,064.1 | 926.3→1,092.8 | -20.7건/일 |
| ST-3358 고덕비즈밸리 지식산업센터A | 2025-04-09 | 86.2→193.9 | 158.0→212.0 | +53.7건/일 |

변화 차이는 `(주변 사후-사전)-(비교지역 사후-사전)`이다. 주변은 고정 참조 위치의1km,사전/사후 평균은 각각28일 기준이다. 기록이 없는 대여소 일자는0으로 취급하므로 관측 누락과 실제 무이용을 완전히 구분하지 못한다. 양수 수요일이21일 이상인 지역만 사용했지만 실제 운영일 보증은 아니다.

**이 표를 신규 설치의 인과 효과로 해석하지 않는다.** 평행추세·날씨·다른 시설 변화·과거 위치·ID변경을 완전히 검증하지 않았고,비교지역 사전 수요도 동일하지 않다. 연말까지 이용이 있는 대여소로 비교지역을 제한해 생존 편향이 있을 수 있다. 사례 간 수요가 겹치거나 비교지역이 재사용될 수 있어 합산하지 않는다. 음수와 양수 모두 그대로 표시했다.

기존 후보의 점수나 순위는 변경하지 않았다. 제안 후보 자체가 실제로 설치된 결과도 아니다.
