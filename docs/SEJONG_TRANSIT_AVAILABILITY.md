# Phase 4 세종 어울링 공개 자료 확인 — 2026-11-12

## 결론
**현재 확보 자료로 세종은 총량 수준 비교까지만 가능**하다. 대여소별 일/시간 이용량·OD·정류장 연계 취약도는 N/A다. 상세 자료가 세상에 없다고 주장하지 않는다. 이번 작업에서는 재현 가능한 공개 원본 파일을 확보하지 못했으며 추가 자동 수집을 중단했다.

## 공식 근거와 실제 접근
- [공공데이터포털 연도별 이용건수](https://www.data.go.kr/data/15134188/fileData.do): 연간 총량 자료. 보유 yearly.csv에는 세종10행(2017~2025 완전연도와 2026 부분연도)이 있으며 세부 OD는 없다.
- [세담터 메인](https://www2.sejong.go.kr/bigdata/main.do) 및 [빅데이터 이용신청 목록](https://www2.sejong.go.kr/bigdata/metaDataView.do?order_type=rcd): HTTP200. 어울링_수집_대여소정보(file_sn28), 어울링_수집_세종_자전거대여소(file_sn29) 목록을 확인했다.
- 공식 화면의 fncDetail 동작대로 metaDataDetailView.do에 POST하여 설명·컬럼 메타데이터를 확인했다. 대여소 번호/명, 설치·폐쇄일 또는 대여소 구분 항목이 있다. 이것을 실제 대여·반납 이력으로 간주하지 않는다.
- 다운로드 버튼이 연결하는 metaDataRegistrationView.do를 열어 신청인 이메일·연령대·지역 입력과 개인정보 수집 이용 동의가 필요한 절차를 확인했다. 신청을 제출하거나 개인 정보를 임의 입력하지 않았다. 화면에 '즉시 다운로드' 버튼도 있지만 동일 신청 화면으로 연결되므로 인증/신청 절차를 우회하지 않았다.
- [어울링 운영 홈페이지](https://www.sejongbike.kr/)는 서비스 운영 안내다. 실시간 재고를 과거 Trip으로 변환하거나 무단 수집하지 않는다.
- [건축공간연구원 과거 이용 분석](https://www.auri.re.kr/gallery.es?act=view&bid=0006&list_no=863&mid=a10308000000)은 과거 이력 분석의 존재를 보여주지만 해당 보고서가 다운로드 가능한 원본 OD 파일이라는 뜻은 아니다.

## 미확보 상태와 필요한 수동 작업
신청자가 세담터 이용신청에서 실제 연구 목적과 동의를 직접 제출하고 제공받은 원본·출처·기준일·공개 조건을 확인해야 한다. 정류장 API는 TAGO 활용신청과 DATA_GO_KR_API_KEY 설정 또는 공식 CSV가 필요하다. 이 권한/자료가 확보되기 전에는 세종의 새 연계 지표를 생성하지 않는다.
향후 원본에 실제 대여/반납 시각·출발/도착 ID가 있으면 기존 정규화 파이프라인으로 검증한 뒤 추가할 수 있다. 현재는 이 필드가 있다고 추정해 새로운 수집기를 만들지 않았다.

## 기준일 제한
기존 파일의 2026-08-31 부분 누계 표기와 공식 페이지 설명 기준일 차이는 해소되지 않았다. 완전연도와 부분연도는 구분하고 도시별 연간 총량을 같은 모집단처럼 직접 비교하지 않는다.

## 보존·검증
세종 원본·기존 수집기·연간 추세 UI는 변경하지 않았다. 서울·대전 기존 군집·네트워크·유사도·Demo Mode를 보존했다. Phase1~3 실제 실행 결과는 TRANSIT_LINKAGE.md / TRANSIT_VULNERABILITY.md / SPARK_TASHU_PIPELINE.md에 기록했다.
