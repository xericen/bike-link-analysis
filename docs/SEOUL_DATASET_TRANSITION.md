# 서울 데이터셋 전환 검증

검증일: 2026-11-09 (UTC)

서울 열린데이터광장의 공식 종료 안내에 따르면 OA-21229와 OA-21235는 2026-11-16 종료 예정이며 각각 OA-14994와 OA-13252가 대체 서비스로 제시됐다. 그러나 실제 파일 스키마를 확인한 결과 두 대체 자료는 현재 OD 분석 경로의 완전한 대체재가 아니다.

## OA-21229와 OA-14994

| 항목 | OA-21229 | OA-14994 최신 파일 |
|---|---|---|
| 실제 확보 기간 | 2026-10-01~31 | 2026-01-01~06-30 |
| 행 수 | 원본 7,955,264행 | 181행 |
| 집계 단위 | 날짜·시간대·출발/도착 대여소 | 서울 전체 일별 총량 |
| 핵심 컬럼 | 날짜, 시간대, 시작/종료 ST ID, 건수 | `대여일자`, `대여건수` |
| OD·네트워크 | 가능(집계 OD) | 불가능 |
| ID 호환성 | ST ID | 대여소 ID 없음 |

OA-14994 파일 합계는 17,978,991건이다. 현재 OA-21229 자료와 관측 기간이 겹치지 않아 총량 일관성은 직접 검증하지 못했다. 따라서 기존 OA-21229 수집기와 정규화 경로는 유지하며 OA-14994는 일별 도시 총량 보조 자료로만 등록한다.

## OA-21235와 OA-13252

OA-21235는 `RNTLS_ID`의 ST ID를 제공해 2026년 10월 OD ID 2,763개 중 2,762개(99.96%)를 직접 연결했다. OA-13252의 대여소 번호는 현재 확보 파일에서 N 계열 관리번호로 나타나 ST ID와 직접 대응하지 않는다. 그러므로 OA-13252를 OA-21235의 무손실 대체 마스터로 사용하지 않는다.

## 결론

- 전환 상태: **완전 호환 아님**
- 기존 수집기 삭제·변경: 하지 않음
- 미매칭 `X`: 다른 대여소로 추정 연결하지 않음
- 과거 관측 당시 좌표와 현재 마스터 좌표가 같다는 보장은 없음
