# 분석 지표 계산식과 해석

- 서울: 날짜·시간대·OD 집계의 실제 이동 건수를 가중치로 사용한다. 대여·반납 관점 행을 중복 합산하지 않는다.
- 대전: 검증된 개별 Trip을 대여소·날짜·시간 및 OD로 집계한다. 중복과 관리 반납 제외 정책 유지.
- 전체: 상세 이용이 있는 도시의 공통 관측 범위에서 합산하고, 세종 연간 통계는 상세 합계에서 제외한다. 내부 ID=도시::대여소 ID로 충돌을 막고 도시 간 가상 간선은 만들지 않는다.

## 알고리즘

1. K-means: 시간대별 대여 비율(24차원), log1p(대여량), 가능한 경우 주말 비율을 StandardScaler로 표준화한다. k=2~8 중 가능한 범위를 Silhouette로 검토한다. Silhouette는 최대 1,500개 표본, random_state=42를 사용한다. 0.2 미만은 역할 해석 보류. 특징이 동일하거나 표본이 부족하면 불가 상태를 반환한다.
2. ARI: 두 기간에 모두 존재하는 대여소 ID 교집합에서 군집 배정을 비교한다. 군집 번호는 재학습마다 의미가 같지 않으므로 번호 변경만으로 역할 변화를 단정하지 않는다.
3. Cosine: x·y/(||x||||y||), x는 시간대 대여/총 대여와 가능한 주말 비중 벡터다. 절대 규모는 별도 이용량·volume_ratio로 구분한다.
4. PageRank: PR(v)=(1-d)/N+d×Σ[PR(u)×w(u,v)/Σw(u,*)]. 실제 유효 OD 그래프에서 계산한다. 표시용 TOP N 그래프에서 새로 순위를 만들지 않는다.
5. 가중 출차수=Σw(v,*), 입차수=Σw(*,v). 실제 이동 건수 합계이며 단순 이웃 수와 다르다.
6. 매개 중심성: 최단경로 거리는 1/이동량, 큰 그래프에서 min(32,N) 노드 표본·seed=42를 사용한다. 기간 민감도에서 생략한 매개 중심성은 0이 아닌 미계산으로 구분한다.
7. 순유출=대여 R−반납 T. 불균형 비율=(R−T)/(R+T). 지속성=max(양수 관측일 수,음수 관측일 수)/해당 대여소 관측일 수. 도시 전체 달력 일수와 다를 수 있다.

## 역할 후보 규칙

- 저이용·고연결: 이용량 중앙값 이하, 양의 이용량 순위−PageRank 순위 차이가 상위 10%, PageRank 값이 중앙값 이상을 동시에 충족.
- 지속 불균형: 대여+반납 총량 하위 25% 제외 후, 절대 불균형 비율 상위 10%와 방향 지속성 상위 25%를 동시에 충족.
- 시간대 집중: 대여량 하위 25%를 제외하고 최대 시간대 비중 상위 10%.
- 역할 변화: 7일/30일 가중 연결 순위 백분위 차이 절댓값 + 집중 시각의 순환 거리/12 + 해석 가능한 군집 설명 변경 여부. 점수 상위 10%를 후보로 제시. 선택 기간이 짧으면 관측창 부족 경고를 함께 확인해야 한다.
- 임계값은 선택 기간의 실제 분포에서 계산한다. 소수점 표시값을 다시 더해 원래 점수와 같다고 가정하지 않는다.

통합 K-means/후보 표시는 도시별 결과를 모은 것이며 통합 재학습이 아니다. PageRank 등 연결 지표와 이용 패턴 군집은 서로 다른 질문에 답한다. 재고·재배치·날씨 자료가 없으므로 원인이나 운영 효과 수치를 확정하지 않는다.
