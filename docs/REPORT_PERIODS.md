| 구분 | 도시·기간 | 발표 시 용도 |
|---|---|---|
| 5번 PageRank, 6번 불균형, 7번 K-means, 8번 대표 사례 보고서 | 서울, 2026년 10월 | 초기 방법론·사례 설명 |
| README 핵심 지표와 서비스 도시 간 비교 | 서울·대전·세종, 2025-12-01~31 | 같은 관측월의 도시 비교 |

## 발표에서 읽을 문구

“첨부 보고서의 서울 2026년 10월 사례는 분석 방법을 보여 주는 이전 결과입니다. 현재 서비스의 세 도시 비교는 2025년 12월 공통 기간으로 재구성했습니다. 두 결과의 대여량·PageRank 순위·군집·후보를 같은 기간 결과로 혼용하지 않습니다.”

4종 DOCX의 본문에서 서울 2026년 10월 사용을 확인했습니다. 7번 보고서의 7·14·30일 구간도 해당 관측 자료 안의 비교입니다. 보고서 재집계를 수행한 것으로 표현하지 않습니다. 기존 바이너리는 로컬 보관 대상으로 바꾸고 파일 해시는 LOCAL_ATTACHMENTS.json에 남겼습니다.

기간뿐 아니라 대여소 마스터·공간 자료·후보 규칙의 기준 시점도 함께 확인해야 합니다. 도시별 과거 추이는 그 기간의 PageRank·OD·K-means를 모두 새로 계산했다는 뜻이 아닙니다.
