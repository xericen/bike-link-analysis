| 항목 | 적용 결과 |

| AI 맥락 | 도시·기간은 기존 요청 조건으로 고정. 대여소와 후보 ID를 별도 JSON으로 전달하고 서버에서 실제 마스터·현재 기간 scenario_pool에 대조한다. 후보 수치·시나리오는 브라우저 값 대신 서버 저장값을 사용한다. selected_station은 질문 키워드와 무관하게 대상이 되며 대여소 도구의 ID/도시를 고정한다. 후보·대여소는 서로 다른 대상으로 구분한다. 후보 선택은 챕터 이동에서 유지하고 도시·기간 변경에서는 초기화한다. |
| AI 보고서 화면 | 전달된 도시·기간·대여소·후보 패널 및 선택 조합의 추가·중복 면적 카드를 추가. ‘선택 후보로 AI 보고서 작성’은 선택 상태를 유지하며 질문을 준비한다. 실행은 기존 전송 버튼/엔터로 수행한다. |
| OD·데이터 정보 | OD TOP10 기본 접기. 공통 하단 ‘데이터 정보’에 기간·자료명·앵커 출처 링크·분모 차이·품질/해석 한계를 모았다. |
