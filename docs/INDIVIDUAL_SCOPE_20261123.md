# 전체·개별 분석 범위 정렬

## 적용 규칙

- **전체 선택:** 서울·대전·세종을공통2025-12-01~2025-12-31로비교한다.
- **개별 선택:** 해당도시의보유전체기간과확보한도시전역을사용한다. 대시보드·개선후보·신규/재배치·이용분석·AI조건에같은범위를사용한다.
- 기존개별분석은이미전체기간사전집계였으나재발견검증이12월에고정돼있었다. 이번에전체기간의방법실험을새로계산해이부분도맞췄다.
- 지도는공식경계와확보좌표가있는전역을사용한다.미확보위치/지역자료를생성해채우지않는다.
- 과거검증자료의명시적reference=2025-12상세링크는해당실험의참조보기로보존한다. 일반개별선택의기본분석범위를12월로바꾸지않는다.

서로기간이다르므로개별총량을합산해도시전체공통값으로쓰지않는다. 관측일수는실제대여기록이있는날이며기간의모든날짜가완전하다는뜻이아니다. 대전의시스템장애등기존결측/부분관측한계를유지한다.

같은46개사전지정조합을개별전체기간의이용상위10·공백조건상위10·1km구역가림으로실행했다. 전체414조건·828개@10/@20일대일매칭지표와간격조건을확인했다.각도시OD총합이기존전체기간scope.rental_count와일치했다.숨긴ID/관련OD는입력에서제외했다.

위값은보유전체기간의탐색최고값이며새운영추천점수나독립예측성능이아니다.50m진단은기존대여소와의간격을완화한별도목적이며신규설치추천으로주장하지않는다.고정위치/시설참조의과거동일성·실제설치/환승효과는미검증이다.

## API·화면·AI

- 기존 /api/method-validation?city=all&scope=common:기존공통12월실험.
- 개별 /api/method-validation?city=seoul|daejeon|sejong&scope=individual:정확한도시전체기간실험.미준비/불일치면12월로대체하지않는다.
- WIZ는전체선택여부에따라scope를전달한다.개별화면에는전체기간·관측량·방법실험만표시하고공통12월/6·7·8월연구가현재개별결과처럼섞이지않는다.
- React개별개선화면도같은전체기간자료를사용한다.도시비교는기존대로공통12월이다.
- get_method_validation에전체기간context가전달되면개별저장근거를반환한다.일치하지않는부분기간은거부한다.원래공통12월도구출력은유지한다.
- AI구조화보고서는전체기간실험에존재하지않는수요사분면알고리즘을사용했다고표시하지않도록수정했다.
