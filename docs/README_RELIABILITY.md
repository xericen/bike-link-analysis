## 파라미터 강건성

원본은 data/reference/method_validation_202512.json이다. 2025년12월, 앵커 반경300/500/800m, 격자250/500/750m, 균등·수요우선·공백우선 가중치를 비교했다. JSON sensitivity에 정확 가중치·후보수·exact Jaccard·지리적 TOP10 겹침·공통 순위 이동·합집합 면적을 보존한다. 격자가 바뀌면 300m 이내 일대일 대응을 사용한다. 순위 이동 null은 공통 ID 비교가 불가능한 경우이며 0으로 해석하지 않는다. 민감도가 낮다는 사실만으로 방법 정확성을 증명하지 않는다.

## 시간 강건성

원본은 docs/conclusion-20261123/results.json이다. 세 도시의 완전한 공통2025년1월·4~12월만 사용한다. 2·3월은 날짜 불완전으로 제외한다. 후보는 고정 공간 참조와 기존 균등 점수에 공통10개월의 주변관측수요를 적용해 다시 순위화했다. 월별 TOP10 재등장은 같은 관측자료의 사후 점검이며 독립 미래 예측 성공이 아니다.

common_cities에 도시별 관측일·총량·연계OD·좌표 미연결 비중, 각 후보의ID·행정구·주변1km수요·단독 추가면적·월별재등장 분모·앵커·연결상태·모델시간을 보존했다. 단독 후보 면적을 단순 합산하면 겹침을 이중 계산하므로 조합 면적으로 인용하지 않는다.

경로는 최근접 앵커와 해당 앵커300m 내 이용·좌표 확인 반납소를 연결한다. 모든 앵커/반납소 조합의 최적화가 아니다. 현재 OSM bike+foot에 대여/반납120초를 더하며 접속오차50m 기준을 사용한다. 경로 미확인과 반납소 미확인은 직선거리로 대체하지 않는다. 대전2위는 연결돼도 도보보다 모델시간이 길어 우선도 재검토다. © OpenStreetMap contributors; 경로 출처 https://routing.openstreetmap.de/about.html.

## 방법 검증

원본은 data/reference/method_validation_202512.json 및 docs/recovery-evaluation-20261123/{seoul,daejeon,sejong}.json이다. 초기12월 high_usage fold는 목표10개 중 기존종합점수0/10씩을 재발견했다. 숨긴 대여소와 관련 OD를 훈련자료에서 제거한 감사 기록과 수요만·시설/인구만·무작위 비교를 보존했다.

후속 실험은6월에서 격자/방법을 선택·잠금하고7월 별도 평가한다. gap_high_usage, gap_random, spatial_block 세 fold를 모두 JSON에 남겼다. TOP10 복구 반경300m·일대일 매칭, 목표분모·후보가능수·hits10/20·Recall·무작위30회 결과·복구된쌍의 평균거리를 구분한다. 겹치는 fold를 독립표본으로 합산하지 않는다. 공간블록의 목표가10보다 많으면 Recall@10의 상한도10/N이다. 모든 fold에서 기준보다 우수하지 않으므로 운영 순위는 바꾸지 않았다.
