[세종 공식 공개 자료 설명](https://www.data.go.kr/data/15106191/fileData.do)을 확인했으나 ‘환승 유무’ 컬럼의 판정 기준·연계 교통수단·시간 창을 확인하지 못했다. 2025년 4분기 원본 CSV 중 10월 기록 **259,143건은 모두 N**이다. N을 비환승으로 확정하거나 실제 환승률 0%로 계산하지 않는다. 운영기관의 컬럼 정의 확보가 남아 있다.

원본 출발·도착 대여소 ID를 현재 BRT 앵커 근접성과 교차 집계했다. 양 끝 모두 300m 밖 69,363건, 출발 밖·도착 이내 53,056건, 출발 이내·도착 밖 48,683건, 양 끝 이내 86,537건이며 나머지 1,504건은 한쪽 이상 위치 연결이 불확실하다. 전체 합계와 원본 행 수 일치를 검증했다. 이는 환승 기록의 진위 검증이 아니라 **원본 코드와 근접성의 진단용 대조**이다. 2026년 5월 위치 마스터를 2025년 이력에 연결했으므로 과거 위치 동일성도 미확인이다.

화면의 도시 비교와 사례 카드에 연·월을 표시하고 다른 연도의 비율을 성과 순위로 해석하지 않는다. 대전에서 전체 보유 기간을 선택한 경우에도 연구 사례는 2026년 10월임을 별도 표시한다.

## 도로망 검증

[FOSSGIS OSRM 운영 안내](https://routing.openstreetmap.de/about.html)에 따라 현재 OpenStreetMap 도로망의 보행·자전거 경로를 조회했다. 도시별 신규 1·2위와 기존 취약 1위, 총 **9곳 × 2수단 = 18회** 조회했다. 좌표의 도로망 스냅 거리가 50m를 넘는 대전 신규 1위와 세종 신규 1위는 거리 순위에서 제외했다. 7곳의 결과를 활용한다.

서울의 세 사례는 직선거리 순서가 신규 1위 → 신규 2위 → ST-919였으나, 보행거리는 1,556.6m → ST-919 2,054.3m → 신규 2위 2,097.8m 순서로 달라졌다. 각 도시의 유효한 동일 후보 집합에서 직선거리 순위와 경로거리 순위를 비교하며 전체 입지 종합 순위를 도로거리 순위로 대체하지 않는다.

동일한 직선거리 최근접 앵커가 목표이다. 다른 앵커까지의 네트워크 최단 경로를 전수 탐색하지 않았다. 현재 도로망 모델은 관측 당시 경로나 현장 통행 가능성 검증과 다르다. 출입구·장벽·보도 폭은 현장에서 확인해야 한다. 원본 응답, 조회 시각, 응답 해시, 스냅 거리, 단순화 경로를 별도 캐시에 보존했다. 재실행 시 캐시를 사용하고 신규 요청은 초당 1회를 넘지 않는다.

## 후보 3곳과 공간 효과

화면 비교표에는 격자 ID, 앵커 직선거리, 선정 이유, 주변 기존 대여소 1km 관측 수요, 개별 추가 면적, 현장 미확인 항목을 함께 표시한다. 신규 격자 ID와 기존 대여소 ID를 구분한다. 주변 이용량은 후보 간 중복 가능성이 있는 대리변수이며 신규 수요 예측값이 아니다.

| 도시 | 신규 상위 3곳 모두 선택 시 추가 면적(km²) | 후보 간 중복 면적(km²) |
|---|---:|---:|
| 서울 | 0.824530 | 0.022338 |
| 대전 | 0.846868 | 표시 정밀도에서 0 |
| 세종 | 0.844638 | 표시 정밀도에서 0 |

추가 면적은 각 후보 면적의 합이 아닌 합집합에서 기준 영역을 뺀 값이다. 모든 판정은 반올림 전 정밀도를 유지한다. 대전·세종 중복 면적의 1e-10 수준 값은 부동소수점 연산 잔차이며 표시에서만 0으로 읽는다. 부지 소유·허가, 보도 유효 폭·출입구, 횡단 장벽, 설치 비용·운영 용량, 과거·현재 위치 동일성은 확인하지 않았다.

기존 대여소의 300/500/800m 기준 × 균등/접근성/수요 우선 가중치 민감도 표를 유지했다. TOP10 Jaccard와 평균 순위 변동을 공개하므로 기본 점수만 확정 순위로 읽지 않는다. ‘재배치 검토’ 명칭을 유지하며 재고·운영 이동 자료 없이 이동 필요 수량을 생성하지 않는다.

## 알고리즘이 판단을 바꾸는 사례

서울 ST-1481은 관측 대여 926건, 이용량 순위 1,640위이나 PageRank 280위이다. 총량만으로 낮은 우선순위로 처리하는 대신 연결 유지 검토 대상으로 남긴다. PageRank를 실제 환승이나 신규 입지 효과의 증거로 바꾸지는 않는다.

대여량 순으로 인접한 최대 25개를 살피고 대여량 차이가 5% 이내인 쌍 중 시간대 Cosine 유사도가 가장 낮은 사례를 골랐다. 전체 가능한 쌍의 전수 최소값을 뜻하지 않는다.

| 도시 | 대여소·관측량·집중 시간 | 대여소·관측량·집중 시간 | Cosine |
|---|---|---|---:|
| 서울 | ST-790 · 416건 · 17시 | ST-1934 · 433건 · 7시 | 0.288 |
| 대전 | ST1081 · 153건 · 11시 | ST1496 · 153건 · 17시 | 0.250 |
| 세종 | SJ_00367 · 460건 · 8시 | SJ-01001 · 481건 · 21시 | 0.293 |

총량이 비슷해도 현장 관찰·재배치 검토 시간대가 달라진다는 근거이다. 실제 부족이나 실제 이동 필요 수량을 뜻하지 않는다. K-means Silhouette가 약 0.08~0.12인 조건에서는 군집 역할 해석 보류를 유지한다. 알고리즘은 설치 점수에 임의 가산하지 않고 설치·연결 유지·운영 관찰이라는 서로 다른 판단을 보완한다.

## Solar 도구 유무 비교

동일 Solar 모델(solar-mini4-260922), 동일 질문·시스템 지시, temperature=0, 최종 응답 한도 700토큰을 사용했다. 서울·세종의 고정 관측 기간에 대해 각각 한 번의 유효한 쌍을 평가했다. 도구 조건은 실제 운영 도구 get_improvement_ranking/get_transit_linkage를 모델이 선택해 호출한다. 동일 모델의 도구 제거 실험이며 모든 일반 LLM과의 비교가 아니다.

| 조건 | 수치·ID 응답 범위 | 제공한 값의 근거 일치 | 대여소 ID | 구조화 근거 불일치 | 자동 검사 밖 자유 서술 |
|---|---:|---:|---|---:|---:|
| 도구 없음 — 서울 | 0/5 | 해당 없음 | 유보 | 0 | 0 |
| 도구 사용 — 서울 | 5/5 | 5/5 | ST-919 일치 | 0 | 4 |
| 도구 없음 — 세종 | 0/5 | 해당 없음 | 유보 | 0 | 0 |
| 도구 사용 — 세종 | 5/5 | 5/5 | SJ_00515 일치 | 0 | 0 |

미응답을 정답으로 계산하지 않는다. 구조화 값은 후보 수·기존 1위 ID·대여량·앵커거리·연계 OD 비중의 5개이다. 정확도와 별도로 응답 범위를 공개한다. 서울 자유 서술 4개는 자동 검증 밖이다. 특히 마지막 문장의 ‘전체 연계 여행 중’이라는 분모 표현은 원래 지표인 ‘전체 OD 중’과 혼동할 소지가 있어 사람이 수정해야 한다. **구조화 10/10 일치가 전체 서술의 정확성을 뜻하지 않는다.**

준비 중 집계 부재로 실패한 초기 실험(6호출·3,088토큰), 최종 응답 형식이 잘못된 기술 점검(6호출·4,274토큰)을 보존했다. 마지막 공통 종료 지시를 양 조건에 동일하게 적용한 유효 실험은 6호출·4,607토큰이다. 실패를 성공 표본으로 재분류하지 않는다. 사례 2개로 통계적 성능 우위를 일반화할 수 없다.

실제 화면의 새 ‘후보 3곳 근거 보고서’ 버튼도 확인했다. Solar가 get_decision_evidence를 실행했고 결과 카드가 표시됐다. 원문에는 도로 결과를 다른 신규 격자에 연결하고 세종 인구밀도를 대체 사용했다고 서술한 문제가 있었다. 원문은 기본 답변에서 보류하고 실제 도구 결과 요약으로 표시했다. 해당 원문을 회귀 사례로 보존하고 후보별 경로 연결·세종 인구 제외 조건 검사도 추가했다. 자유 서술 전체 검증을 보장하지 않는다.

## 재현 및 배포 준비

아래 명령은 저장소 루트에서 실행한다. 원천 자료와 기존 처리 DB가 준비되어 있어야 한다.

```bash
export PYTHONPATH=.
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python scripts/preprocess/precompute_city_kpis.py --workers 2 --report docs/transit/decision-kpi-build-20261117.json
python scripts/validate/anchor_presentation_audit.py
python scripts/validate/decision_inputs.py
python scripts/collect/audit_candidate_routes.py
# 명시적으로 비교 실험을 갱신할 때만 실행: 기존 Upstage 자격증명·유료 모델 호출 필요
python scripts/validate/solar_paired_evaluation.py
python scripts/validate/decision_evidence.py
python scripts/deploy/release.py --verify-only
```

원본 조건이 같으면 경로 응답 캐시와 기존 유효한 비교 실험을 재사용할 수 있다. 사례의 좌표·앵커·기준 기간은 내용 해시로 검사하고 비교 실험의 정답 값이 바뀌면 재평가를 요구한다. 배포 준비 검사에는 기존 27조합·216집계뿐 아니라 현재 revision과 일치하는 decision-evidence 패키지의 존재도 포함했다. 새 API는 조회 전용이며 요청 중 도로망·LLM·공간 계산을 수행하지 않는다.

배포 아티팩트에는 기존 processed 데이터와 함께 **data/processed/research/** 하위 결과를 포함해야 한다. 이 폴더는 원본 캐시·비밀키와 같이 Git 제외 경로이므로 Git 소스만 복사하면 준비 검사를 통과하지 못한다.
