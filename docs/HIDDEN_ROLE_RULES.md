# 숨은 역할 후보 판정 규칙

검증일: 2026-11-09 (UTC). 모든 임계값은 고정 숫자가 아니라 사용자가 선택한 기간의 실제 대여소 분포에서 다시 계산한다.

## 연구 질문과 수식

| 후보 유형 | 연구 질문 | 계산식·판정 |
|---|---|---|
| 저이용·고연결 | 이용량은 상대적으로 적지만 네트워크 연결 순위가 높은가? | `순위차 = 이용량순위 - PageRank순위`. 이용량 중앙값 이하, 양의 순위차 상위 10%, PageRank 중앙값 이상을 동시에 만족 |
| 유입·유출 불균형 | 대여와 반납의 방향 차이가 여러 관측일에 지속되는가? | `순유출 = 대여-반납`, `불균형비율 = 순유출/(대여+반납)`. 총량 하위 25%를 제외하고 절대 비율 상위 10% 및 방향 지속성 상위 25% 동시 만족 |
| 특정 시간대 집중 | 하루 이용이 특정 한 시간에 과도하게 집중되는가? | `최대시간대비중 = 시간대최대대여/전체대여`. 이용량 하위 25%를 제외하고 최대시간대비중 상위 10% |
| 기간별 역할 변화 | 최근 7일의 역할이 30일 기준과 얼마나 달라졌는가? | `변화점수 = |가중연결순위백분위(7일)-백분위(30일)| + 집중시간거리/12 + 군집역할변경(0/1)`. 이용량 하위 25% 제외 후 점수 상위 10% |

군집 ID는 기간마다 재배열될 수 있으므로 역할 변화는 ID가 아니라 관측 시간대 비중으로 붙인 `cluster_role`을 비교한다. 가중 연결은 입·출 OD 건수 합이다. 매개 중심성은 최대 32개 노드 표본 근사다.

## 2026년 10월 실제 분포 예시

서울 저이용·고연결 기준은 이용량 1,126건 이하, 순위차 435 이상, PageRank 0.00030365 이상이었다. ST-1481은 이용량 1,640위·PageRank 280위(차이 +1,360), ST-452는 1,722위·625위(+1,097), ST-451은 1,515위·445위(+1,070)였다.

대전 불균형 기준은 총 대여·반납 335.5건 이상, 절대 불균형 비율 0.0176 이상, 방향 지속성 0.5909 이상이었다. ST0763은 순유출 -307건, ST0051은 +298건, ST0377은 +235건이었다.

## 신뢰도와 해석 제한

- 7·14일 K-means의 Silhouette가 0.1 미만이면 약한 분리 경고를 표시한다.
- 기간 비교는 두 창에 공통으로 존재하는 대여소만 사용한다.
- 낮은 이용량의 비율 이상치를 줄이기 위해 하위 25% 총량을 후보 판정에서 제외한다.
- 후보는 운영자가 추가 확인할 우선순위이며 재고 부족, 환승·관광 기능 또는 조치 효과를 확정하지 않는다.
- 날씨, 공휴일, 고장, 재고 및 재배치 기록이 없어 인과 설명은 할 수 없다.
