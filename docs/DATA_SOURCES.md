서울 두 자료의 이용허락은 공공누리 1유형(출처표시, 상업적 이용·변경 가능)이다. 대전·세종 공공데이터포털 페이지는 무료 및 이용허락범위 제한 없음으로 표시한다. 부산 웹 표의 재이용 조건은 별도 확인이 필요하다. 공공데이터포털의 자동변환 OpenAPI는 회원가입·활용신청이 필요하며 키 없이 호출하지 않았다. [대전교통공사](https://www.djtc.kr/)가 운영하는 타슈의 공식 대여이력 원본은 공공데이터포털 15137219에서 확인했다.

공공데이터포털 페이지에 포함된 공식 Swagger 문서에서 자동변환 OpenAPI 경로를 확인했다. [대전 Swagger](https://infuser.odcloud.kr/oas/docs?namespace=15062798/v1): `GET https://api.odcloud.kr/api/15062798/v1/uddi:1b7e5971-a37d-4a80-ad0f-9aa12d1e2b87`; [세종 Swagger](https://infuser.odcloud.kr/oas/docs?namespace=15134188/v1): `GET https://api.odcloud.kr/api/15134188/v1/uddi:9ab74c31-6b18-4a9e-bc53-d60058a015c5`. 두 경로 모두 `serviceKey` 또는 Authorization 인증을 요구한다. 상태는 **ACCESS_REQUIRED**이며 실제 인증 호출·응답 스키마는 검증하지 못했다. `DATA_GO_KR_API_KEY`를 `.env`에 넣은 후 지역 수집기에 `--api`를 주면 페이지별 JSON을 CSV로 저장한다. 이 API 원본은 파일 CSV와 별도로 저장하며 스키마 재확인 전 분석에는 연결하지 않는다.

서울 2026년 10월 월간 OD ZIP을 공식 다운로드해 연결했고, 대전 기존 공식 ZIP의 월별 파일 11개를 모두 처리했다. 부산 통합 이용 파일과 세종 세담터 신청 대상 원본은 확보하지 못했다. 서울의 2015년 대여이력 파일은 스키마 확인에만 사용한다. 로컬 파일은 `python -m scripts.collect.collect_<city> --dataset <source_id> --file <같은 형식의 파일>` 또는 화면의 정규화 CSV 업로드로 가져올 수 있다. 업로드 자료는 **스키마만 검증**하며 공식 출처와 라이선스는 제출자가 확인해야 한다.

분석 제한: 서울은 31일 집계 OD, 대전은 335일 개별 Trip이다. 같은 날짜를 필터링해도 모집단·운영방식·집계 방식이 달라 총량의 단순 비교에는 한계가 있다. 세종·부산에는 시간대별 대여소 이용 원본이 없어 K-means/유사도/네트워크를 비활성화한다. 서울 OD ID 2,763개 중 2,762개만 현재 공식 마스터 좌표와 직접 연결하며 `X`는 제외한다. 현재 좌표가 관측일 당시 좌표와 동일한지는 검증되지 않았다.
