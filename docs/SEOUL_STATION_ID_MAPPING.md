# 서울 대여소 ID 대응 검증

2026-11-09 공식 [서울시 따릉이대여소 마스터 정보](https://data.seoul.go.kr/dataList/OA-21235/S/1/datasetView.do) 시트에서 3,434행을 조회했다. 공식 시트의 데이터 조회 엔드포인트 `/dataList/dataView.do`를 사용했고, 원본 컬럼은 `RNTLS_ID`, `ADDR1`, `ADDR2`, `LAT`, `LOT`이다. ID 중복은 0건이다. 이 서비스는 서울시 공지에 따라 2026-11-16 종료 예정이며 OA-13252가 대체 서비스로 안내됐다.

기존 위치 목록은 관리번호 `N-...` 체계로 서울 OD의 `ST-...`와 직접 일치하지 않았다. 공식 마스터의 `RNTLS_ID`는 OD의 `ST-...`와 일치한다. 2026년 10월 OD 고유 대여소 ID 2,763개 중 2,762개를 마스터에서 찾았고 이름 및 서울 인근 범위의 유효 좌표를 확인했다. 매칭률은 99.96%이다. 미매칭 ID는 `X` 1개다. `X` 관련 일별 OD는 14,397행, 이동 건수 합계 18,535건이며 공식 마스터에서 뜻을 확인하지 못했다. 이 ID는 지도 및 중심성 그래프에서 제외하고, 원본 OD 기록은 보존했다. 가까운 대여소에 임의 연결하지 않았다.

`scripts/preprocess/map_seoul_stations.py`를 다시 실행하면 공식 자료를 조회해 확인된 좌표만 `data/processed/stations.csv`에 반영한다. 상세 검증 결과 및 미매칭 전체 목록은 `data/processed/seoul_station_mapping.json`에 저장된다. 원본 마스터의 `ADDR2`가 비면 `ADDR1`을 이름으로 사용한다. 이름 중복으로 자동 매칭하지 않으며 ID 직접 일치만 사용한다.

주의: 마스터는 현재 시점 자료이고 OD 관측 기간은 2026-10-01~31이다. 위치가 각 관측일에도 같았는지는 이 자료만으로 확정할 수 없다. 대여소별 역사 좌표 자료가 확보되면 시점 검증이 필요하다.
